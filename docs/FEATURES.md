# 功能与兼容范围

当前版本：0.1.0，实验阶段。本机单帐号；版本适配尚未扩展到其他构建。

## 当前能力

| 功能 | 状态 | 边界 |
| --- | --- | --- |
| ELF 识别、能力报告 | 可用 | 默认诊断模式；不附加微信 |
| 搜索联系人、搜索群 | 原生原型已验证 | 有界搜索，不是完整通讯录导出 |
| 读取历史消息 | 原生原型已验证 | 白名单会话，每处最多 20 条；无实时订阅 |
| 发送私聊文本、群文本 | 原生原型已验证 | 白名单与持久幂等键；未确认收件端送达 |
| 图片、文件 | 研究中，未开放 | 上传、缓存和消息提交链路仍待验证 |
| 普通表情、自定义表情、GIF | 计划 | 暂无独立的表情工具或完整兼容性验证 |
| 实时消息事件、@群成员 | 计划 | 纯文本中的“@名字”不等于真实提及 |
| 完整好友信息、修改好友备注 | 计划 | 搜索返回的信息不等于完整好友详情 |
| 添加好友、检查/接受申请 | 计划 | 未暴露任何好友管理写操作 |
| 创建群聊、邀请入群、群成员 | 计划 | 后续逐项验证 |
| 群置顶消息、发布/编辑群公告 | 计划 | 后续逐项验证 |
| 开关群聊邀请确认 | 计划 | 定义为入群需群主或管理员同意 |
| 读取/发表朋友圈、UI 截图 | 计划 | 当前 MCP 中不可执行 |

内部操作名称或注册信息只能作为研究线索。服务只在启用原生后端时暴露已实现的业务工具，未验证能力不会被宣称为可调用。

## 验证范围

原生原型对专用测试联系人和测试群分别提交过一条文本，客户端发送管线返回成功；通过真实 MCP 会话在两处历史消息中找到了测试标记。客户端重新登录后再次完成历史查询。以上均未证明收件端收到或已读。

自动测试验证 stdio 协议、输入约束、白名单拒绝、跨进程幂等、错误恢复和消息 ID 精度。隔离替身覆盖的语义不冒充真实微信集成。

图片缓存库加载实验中客户端曾退出，原因未确定。实验已停用，未发送图片，未写入真实图片缓存。发布运行路径仅使用已验证的 executor 桥接。

原始结果与实验探针留在本地，不提供真实帐号、联系人、群 ID 或聊天原文。
