# weskill 能力与兼容范围

weskill 以一个 Skill 编排微信操作，以下状态对应其配套 MCP 的实际执行能力。

当前版本：0.3.0，实验阶段。本机单帐号；版本适配尚未扩展到其他构建。

## 当前能力

| 功能 | 状态 | 边界 |
| --- | --- | --- |
| ELF 识别、能力报告 | 可用 | 默认诊断模式；不附加微信 |
| 搜索联系人、搜索群 | 原生原型已验证 | 可自定义结果条数和排序，使用微信原生搜索 |
| 读取历史消息 | 原生原型已验证 | 默认20，自定义条数或拉全部；无实时订阅 |
| 发送私聊文本、群文本 | 原生原型已验证 | 用户指定目标与持久幂等键；客户端返回成功即按发送成功处理 |
| 本地图片、文件 | 原生私聊与普通群已验证 | 本机路径；PNG、文本文件实测，其他格式未逐项验证 |
| 普通表情、自定义表情、GIF | 计划 | 暂无独立的表情工具或完整兼容性验证 |
| 实时消息事件 | 计划 | 尚无订阅工具 |
| 真实 @群成员/@所有人 | 原生已验证 | 原生提及元数据与可读正文一起发送 |
| 好友资料、修改好友备注 | 原生已验证 | 本地可用完整记录；昵称/备注/微信号/签名/地区/头像/电话列表/标签/来源等，不宣称远端刷新 |
| 检查好友申请记录 | 原生已验证 | 默认20，自定义条数或全量；区分原生状态与未知 |
| 搜索新联系人 | 原生已验证 | 使用微信原生搜索，验证凭据留在内部 |
| 添加好友、接受申请 | 已接入，真实写入待验证 | 复用原生搜索/申请记录凭据；已有好友、不存在申请的不提交路径已验证 |
| 创建群聊、邀请入群、群成员 | 原生已验证 | 返回新群 ID、邀请结果或成员 ID、群昵称、本地资料与角色；邀请提交不等于接受 |
| 移出群成员 | 原生已验证 | 写操作前刷新本人角色，仅群主或管理员可提交；支持多个成员 ID |
| 群置顶消息、发布/编辑群公告 | 原生已验证 | 置顶/取消使用服务器消息 ID；公告目前为完整纯文本替换 |
| 开关群聊邀请确认 | 原生已验证 | 入群需群主或管理员同意；检查原生网络和逐项操作结果 |
| 读取/发表朋友圈、UI 截图 | 计划 | 当前 MCP 中不可执行 |

内部操作名称或注册信息只能作为研究线索。服务只在启用原生后端时暴露已实现的业务工具，未验证能力不会被宣称为可调用。

## 验证范围

原生原型对专用测试联系人和测试群分别提交过一条文本，客户端发送管线返回成功；通过真实 MCP 会话在两处历史消息中找到了测试标记。客户端重新登录后再次完成历史查询。本项目以客户端返回成功作为发送成功标准。

群管理在普通测试群验证了成员/角色查询、建群、邀请、移出成员、真实 @成员与全体、公告发布/编辑/清空、消息置顶/取消，以及邀请确认开启/关闭。测试公告已清空、测试置顶已取消、邀请确认已设回测试前的关闭状态。原生调用不占用鼠标或键盘焦点，流程见 [群管理说明](GROUPS.md)。

自动测试验证 stdio 协议、输入约束、目标格式校验、跨进程幂等、错误恢复和消息 ID 精度。隔离替身覆盖的语义不冒充真实微信集成。

图片缓存库加载实验中客户端曾退出，原因未确定。该缓存库实验已停用。当前媒体实现直接按已恢复的缓存布局放置本机文件，复用现有 executor 和通用发送入口；不加载该实验库。私聊图片、文件均取得客户端成功回调，未额外回查历史。

原始结果与实验探针留在本地，不提供真实帐号、联系人、群 ID 或聊天原文。

## 开发范围

好友管理的资料、备注与申请记录已验证；主动添加和接受申请继续联调，见 [好友管理说明](FRIENDS.md)。群成员昵称和资料已共用联系人资料查询能力。

公告以纯文本、拉人入群以邀请路径为产品范围。普通群 PNG 和文本文件发送已获得客户端成功回调。

其他 Linux 架构继续适配；当前原生执行依赖 AArch64 指令、调用约定与已验证构建地址，保留必要构建检查。诊断层没有额外架构限制。
