# weSkill 0.4.2

weSkill 为 Linux 微信提供五个 Skill 与 31 个本机 MCP 工具，覆盖消息与媒体、好友、群管理、系统与自定义表情、朋友圈。

- 新增 npm 安装包与 `weskill` CLI，显式准备独立 Python 环境和原生桥。
- 一键注册 Codex、Claude Code；为其他 Agent 平台导出 stdio MCP 配置和完整 Skill 目录。
- 共享原生执行桥，按回调所有权释放完成的业务脚本。
- 提供构建兼容性诊断、公开开发指南与玻璃风格图标。
- GitHub Actions 测试、版本打包与 npm OIDC 发布流程。

## 安装

```bash
npm install -g weskill@0.4.2
weskill setup
weskill install codex
# 或 weskill install claude
```

原生业务适配 Linux ARM64 微信 4.1.13.26 的指定构建，需 Python 3.12+、GCC 和已登录客户端。其他支持本机 stdio MCP 的 Agent 使用 `weskill config` 接入；验证范围见仓库文档。

附件包括 npm tarball、Python wheel、源码包、五 Skill 插件 ZIP 和 SHA256 校验值。账号数据、研究报告与内部规划均不包含在发布包中。
